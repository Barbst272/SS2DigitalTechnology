# SS2 Digital Technologies Workbench

> **Senior Secondary School (SS2) First Term Interactive Learning & Examination Suite**  
> Aligned with the NERDC Curriculum and WAEC / NECO Examination Standards.

---

## 🌟 Overview

The **Digital Technologies Workbench** is an all-in-one, offline-first digital learning laboratory and computer-based testing (CBT) platform. It provides secondary school students with comprehensive lesson notes, interactive simulators, hands-on office suite practice, and timed assessments.

---

## 🚀 Key Features

- **🌟 Minimalist Welcome Portal:** Clean, modern landing page with instant navigation to notes, practical labs, CBT assessments, and student dashboards.
- **📘 Complete Curriculum Scheme Notes:** In-depth coverage of all 8 First Term topics with detailed explanations, comparison tables, real-life examples, and printable study handouts.
- **⚡ Interactive Practical Labs:**
  - **Logic Gates & Truth Tables:** Live interactive gate simulators (AND, OR, NOT, NAND, NOR, XOR, XNOR).
  - **SQL Database Lab:** Hands-on SQL querying on school databases.
  - **Network Simulator:** Visual topology simulator with packet transmission and ping tests.
  - **Cybersecurity Lab:** Password entropy strength analyzer and phishing threat detector.
- **📝 Office Suite Practice:**
  - Word Processor with rich text tools.
  - Spreadsheet with formulas (SUM, AVERAGE, MIN, MAX, COUNT, IF).
  - Presentation Builder with slide layouts and slideshow preview.
  - Practice Email Client (Outlook) & Digital Class Notebook (OneNote).
- **⌨️ Computer Skills Practice:** Typing Speed & Accuracy Tutor, File Explorer simulator, Task Manager monitor, and Paint canvas.
- **🖥️ Configurable CBT Examination Engine:**
  - Expanded question pool (60+ WAEC/NECO questions).
  - Customizable question count, time duration, and topic scope.
  - Shuffled questions and options, flag for review, and instant grading.
  - Comprehensive answer explanations and topic performance breakdown.
- **🏆 Certificate & Progress Report:**
  - Official Certificate of Competence with seal and verification code.
  - Printable Student Progress Report with term-long topic and CBT breakdown.
- **♿ Full Accessibility Suite:**
  - 4 Visual Themes: Light, Dark, Sepia (Eye-Care), and High Contrast.
  - Built-in Voice Reader (Text-to-Speech) for auditory learners.
  - Dyslexia-friendly mode and Reading Guide Ruler.
  - Full Keyboard Navigation (<kbd>Alt</kbd> + <kbd>W</kbd>, <kbd>H</kbd>, <kbd>1..8</kbd>, <kbd>F</kbd>, <kbd>G</kbd>, <kbd>C</kbd>, <kbd>A</kbd>, <kbd>T</kbd>, <kbd>R</kbd>).

## 💻 How to Run

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Barbst272/SS2DigitalTechnology.git
   ```
2. Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari).
3. **No server, node, or internet connection required** — 100% client-side and offline capable!

---

## 🌐 Live GitHub Pages Deployment

To enable GitHub Pages:
1. Go to **Settings** > **Pages** in this GitHub repository.
2. Under **Source**, select `Deploy from a branch`.
3. Choose the `main` branch and `/ (root)` folder, then click **Save**.
4. Your workbench will be live at: `https://barbst272.github.io/SS2DigitalTechnology/`
